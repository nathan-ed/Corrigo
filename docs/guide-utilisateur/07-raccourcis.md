# Raccourcis clavier

`Ctrl` est `Cmd` sur macOS, `Maj` est la touche Majuscule (Shift).

## Fichiers et documents

| Touches | Action |
|---|---|
| `Ctrl+O` / `Ctrl+Maj+O` | ouvrir des fichiers / un dossier |
| `Ctrl+S` | sauvegarder les annotations |
| `Ctrl+E` / `Ctrl+Maj+E` | exporter la copie / tout exporter |
| `Ctrl+R` | renommer le fichier PDF |
| `Ctrl+W` | fermer le document |
| `Ctrl+Q` | quitter |
| `Ctrl+Alt+←` / `Ctrl+Alt+→` | fichier précédent / suivant de la liste |
| `Ctrl+Alt+Maj+←/→`, `Alt+Page préc./suiv.` | fichier précédent / suivant, en restant à la même page (ou à la page de l'exercice) |
| `←` `→` (vue en colonne) | fichier précédent / suivant |
| `↑` `↓`, `Page préc./suiv.`, `Début`, `Fin` | se déplacer dans le document |
| `Ctrl+Alt+↑` / `Ctrl+Alt+↓` | page précédente / suivante |
| `Ctrl+-`, `Ctrl++`, `Ctrl` + molette | zoom |
| `Ctrl+↓` | ajuster à la largeur de la page |
| `Ctrl+Z` / `Ctrl+Maj+Z` | annuler / rétablir |
| `Ctrl+B` | afficher / masquer les panneaux latéraux |
| `F11` | plein écran |

## Annotations

| Touches | Action |
|---|---|
| double-clic sur la page, `Ctrl+T` | nouveau texte |
| `Ctrl+1`…`9` | insérer l'un des neuf premiers textes favoris |
| `Ctrl+Alt+1`…`9` | couleur de l'élément sélectionné |
| `Ctrl+Alt++` / `Ctrl+Alt+-` | taille du texte sélectionné (ou épaisseur du trait d'un dessin) |
| `Ctrl+D` | nouveau dessin à main levée |
| `Ctrl+A`, `Suppr` | sélectionner tous les éléments de la page, supprimer la sélection |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | couper / copier / coller |

## Correction

| Touches | Action |
|---|---|
| `Ctrl+G` | nouvelle note au même niveau (onglet Barème) |
| `Ctrl+N` | prochaine note à saisir |
| `Alt+↑` / `Alt+↓` | exercice précédent / suivant (panneau de correction) |
| `Alt+1`…`9` | aller à la page de l'exercice 1…9 |
| `Ctrl+Maj+G` | aller au panneau de correction |
| `1`…`9` | ajouter la n-ième méthode ou erreur (voir plus bas) |
| `#`, `Ctrl+Maj+M` | ajouter une méthode ou une erreur à la souris |
| `Ctrl+Maj+N` | nouvelle note personnelle |
| `Ctrl+Maj+S` | note personnelle avec capture |

Dans le panneau de correction : `1`…`9` ajoutent la n-ième méthode ou erreur, `⌫` enlève la dernière, `0` zéro,
`=` tous les points, `↑` `↓` sous-note, `←` `→` copie, `Tab` / `Maj+Tab` champs, `C` commentaire, `G` commentaire
général, `Z` / `Maj+Z` copie non corrigée suivante / précédente, `Échap` retour au document ([détails](03-correction.md#clavier-dans-le-panneau)).

## Correction par lignes

Tout se fait au clavier, sans quitter le texte de l'exercice.

| Touches | Action |
|---|---|
| `Entrée` | nouvelle ligne (un texte et ses points : « Notation -0.5 ») |
| ligne vide | sous-question suivante (« b) » en tête de bloc choisit la sous-question) |
| `↑` `↓` puis `Tab` | prendre une ligne déjà utilisée, proposée sous le champ en tapant |
| `Échap` | masquer les lignes proposées ; annuler une marque PNF en attente |
| « g » après les points | ligne proposée dans tous les exercices du test (« Notation -0.5 g ») |
| `Alt+Entrée` | placer toutes les lignes à côté des notes |
| `Maj+Tab` | taper à la main la note de la sous-question du curseur (✎) ; `Entrée` ou `Tab` la valide, `Échap` l'annule, et on revient au texte |
| `Alt+↑` / `Alt+↓` | exercice précédent / suivant |
| `Alt+Page préc./suiv.` | copie précédente / suivante, même exercice |
| `Ctrl+Entrée` / `Ctrl+Maj+Entrée` | copie non corrigée suivante / précédente (deux fois de suite si des lignes ne sont pas encore placées) |
| `Ctrl+Z` / `Ctrl+Maj+Z`, `Ctrl+Y` | annuler / rétablir dans le texte (juste après un clic de placement : annule ce placement) |
| `Ctrl+S` | sauvegarder |
| `Ctrl+Maj+L` | points à vérifier sur toutes les copies (copies pas corrigées, lignes pas placées, notes ✎, sous-questions pas notées) : `Entrée` ouvre la copie sur l'exercice et cache la liste, `Ctrl+Maj+L` la ramène, relue |

Une lettre tapée hors d'un champ (après un clic sur la copie) va dans le texte, sur une nouvelle ligne.

La souris sur la copie, `1`…`9` mettent la n-ième méthode ou erreur de la carte à l'endroit de la souris.

Les raccourcis des figures et des images se définissent par un clic droit sur elles dans l'onglet Dessin.
