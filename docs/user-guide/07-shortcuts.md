# Keyboard shortcuts

`Ctrl` is `Cmd` on macOS.

## Files and documents

| Keys | Action |
|---|---|
| `Ctrl+O` / `Ctrl+Shift+O` | open files / open a folder |
| `Ctrl+S` | save the annotations |
| `Ctrl+E` / `Ctrl+Shift+E` | export the copy / export all |
| `Ctrl+R` | rename the PDF file |
| `Ctrl+W` | close the document |
| `Ctrl+Q` | quit |
| `Ctrl+Alt+←` / `Ctrl+Alt+→` | previous / next file of the list |
| `Ctrl+Alt+Shift+←/→`, `Alt+Page Up/Down` | previous / next file, staying on the same page (or the exercise page) |
| `←` `→` (column view) | previous / next file |
| `↑` `↓`, `Page Up/Down`, `Home`, `End` | move in the document |
| `Ctrl+Alt+↑` / `Ctrl+Alt+↓` | previous / next page |
| `Ctrl+-`, `Ctrl++`, `Ctrl` + scroll | zoom |
| `Ctrl+↓` | fit the page width |
| `Ctrl+Z` / `Ctrl+Shift+Z` | undo / redo |
| `Ctrl+B` | show / hide the sidebars |
| `F11` | full screen |

## Annotations

| Keys | Action |
|---|---|
| double-click on the page, `Ctrl+T` | new text |
| `Ctrl+1`…`9` | insert one of the first nine favorite texts |
| `Ctrl+Alt+1`…`9` | color of the selected element |
| `Ctrl+Alt++` / `Ctrl+Alt+-` | size of the selected text (or line width of a drawing) |
| `Ctrl+D` | new freeform drawing |
| `Ctrl+A`, `Delete` | select all the elements of the page, delete the selection |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | cut / copy / paste |

## Grading

| Keys | Action |
|---|---|
| `Ctrl+G` | new grade at the same level (Grades tab) |
| `Ctrl+N` | next grade to enter |
| `Alt+↑` / `Alt+↓` | previous / next exercise (grading panel) |
| `Alt+1`…`9` | go to the page of exercise 1…9 |
| `Ctrl+Shift+G` | focus the grading panel |
| `1`…`9` | add the n-th method or mistake (see below) |
| `#`, `Ctrl+Shift+M` | add a method or a mistake at the mouse |
| `Ctrl+Shift+N` | new personal note |
| `Ctrl+Shift+S` | personal note with a screenshot |

In the grading panel: `1`…`9` add the n-th method or mistake, `⌫` remove the last one, `0` zero, `=` full points,
`↑` `↓` sub-grade, `←` `→` copy, `Tab` / `Shift+Tab` fields, `C` comment, `G` general comment, `Z` / `Shift+Z` next / previous
ungraded copy, `Esc` back to the document ([details](03-grading.md#keyboard-in-the-panel)).

## Grading by lines

Everything is done with the keyboard, without leaving the text of the exercise.

| Keys | Action |
|---|---|
| `Enter` | new line (a text and its points: "Notation -0.5") |
| blank line | next sub-question ("b)" at the start of a block chooses the sub-question) |
| `↑` `↓` then `Tab` | take a line already used, offered under the field while typing |
| `Esc` | hide the offered lines; cancel a pending PNF mark |
| "g" after the points | line offered in every exercise of the test ("Notation -0.5 g") |
| `Alt+Enter` | place all the lines next to the grades |
| `Shift+Tab` | type by hand the grade of the sub-question of the caret (✎); `Enter` or `Tab` applies it, `Esc` cancels it, and the text gets the focus back |
| `Alt+↑` / `Alt+↓` | previous / next exercise |
| `Alt+Page Up/Down` | previous / next copy, same exercise |
| `Ctrl+Enter` / `Ctrl+Shift+Enter` | next / previous ungraded copy (twice in a row if lines are not placed yet) |
| `Ctrl+Z` / `Ctrl+Shift+Z`, `Ctrl+Y` | undo / redo in the text (right after a click that placed a line: undoes that placement) |
| `Ctrl+S` | save |

A letter typed outside a field (after a click on the copy) goes to the text, on a new line.

With the mouse on the copy, `1`…`9` put the n-th method or mistake of the card at the mouse position.

The shortcuts of figures and images can be set by right-clicking them in the Paint tab.
