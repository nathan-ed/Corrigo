# Personal notes

Notes are for you only: they are never written on the copies. Use them for anything you want to remember while
grading ("check the scale of Q3 with a colleague", "this student copied the neighbour?", "good example to show in
class").

- `Ctrl+Shift+N`: new note, from anywhere. Type it, `Enter` to save, `Shift+Enter` for a new line.
- `Ctrl+Shift+S`: screenshot note. Drag on the copy to select a region (a click takes the whole page), then write the
  note. `Esc` cancels.
- **Notes** tab (book icon): all the notes, newest first, with the copy and page they were taken on.
  - **Search the notes**; **Only the notes of this copy**.
  - **Go to the copy** opens it at that page.
  - Click a screenshot to enlarge it; click a note's text to edit it; delete a note from its menu.

Notes taken on a copy are stored in its evaluation folder (`.pdf4teachers/notes.yml`, screenshots in
`.pdf4teachers/notes/`). Notes taken with no copy open are kept in the app's data folder.
